A aplicação "Cátalogo de cartas cookie run: kingdom" foi criada justamente como uma forma de catalogar cartas do jogo cookie run: kingdom e editalas de forma rápida e simples. Sua estrutura e visual foram inspirados no catálogo oficial do jogo, mas diferente do site oficial, a aplicação dá liberdade para o usuário customizar suas cartas com a imagem que preferir e favoritar suas cartas preferidas.
